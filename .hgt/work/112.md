# Issue 112 — fix: drop TMPDIR from the sandbox prefix — it breaks srt's bridge sockets

## Task (verbatim from the issue body)

## Context
First live `hgt work` after #95 (PR #105): `Error: Failed to create bridge sockets after 5 attempts`.

## Problem
The `env -i` prefix sets `TMPDIR=<worktree>/.hgt/tmp`. Host-side srt binds its socat bridge sockets at `os.tmpdir()/claude-http-<16hex>.sock` (0.0.67, linux-sandbox-utils.js:436) — ~113 chars, over the 107-byte AF_UNIX limit. The bind fails silently; srt gives up after 5 polls. The setting was dead weight anyway: SRT overrides the jail's TMPDIR to `/tmp/claude` (default-writable; `CLAUDE_CODE_TMPDIR` is the seam to move it), so only host srt ever saw hgt's value.

## Scope
Drop `TMPDIR=$_SANDBOX_SCRATCH` from `sandbox_argv`; keep `GH_CONFIG_DIR`. Fix what was built on the wrong model: README known-friction, ADR 0007 amendment, and the test pinning `srt-env TMPDIR=<scratch>` (assert absence instead).
