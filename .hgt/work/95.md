## Context
[ADR 0007](docs/adr/0007-issue-92-sandbox-mechanism.md) (spike #92, PR #94) resolves the
mechanism question: adopt `@anthropic-ai/sandbox-runtime` (SRT), pinned, covering **both**
#67 (filesystem) and #74 (egress) in one dependency. It supersedes ADR 0005's mechanism —
not its threat model, not its wrap-claude-only constraint, not its fail-closed posture.

The load-bearing property: SRT's jail is `--unshare-net` and forwards loopback to its proxy
over a unix socket, so a program that ignores `HTTPS_PROXY` gets **no network** rather than an
unfiltered one. No host firewall, no cgroup scope, no `systemd-run`, no polkit.

## Scope
Rewrite `lib/sandbox.sh` around SRT. `sandbox_argv` stops assembling bwrap flags and starts
generating a settings file:

```sh
srt --settings <worktree>/.hgt/srt.json claude -n 'hgt/<n>-<slug>' '<prompt>'
```

```json
{
  "network":    { "allowedDomains": ["api.anthropic.com", "<git remote host>"] },
  "filesystem": {
    "denyRead":   ["~/"],
    "allowRead":  ["~/.nvm", "~/.local", "~/.gitconfig"],
    "allowWrite": ["<worktree>", "<git-common-dir>", "~/.claude", "~/.claude.json", "/tmp"]
  }
}
```

Four things that must not regress, each a documented residual in ADR 0007:

1. **Scrub the environment yourself.** SRT never emits `--clearenv`, so the jail **inherits
   the full environment of whatever invoked `srt`**. Its `credentials.envVars` key is a
   denylist (`deny` → bwrap `--unsetenv`, `mask` → sentinel + proxy substitution) — you must
   name each variable. ADR 0005 cleared everything and named the survivors, which is strictly
   stronger: you can't forget to deny a var you never knew was exported. Invoke `srt` from an
   `env -i` baseline carrying only `_SANDBOX_ENV_PASS`, or a `GH_TOKEN` exported in the host
   shell walks straight into the jail.
2. **Reads default to *allowed*** in SRT (deny-then-allow). ADR 0005's tmpfs-`$HOME` is
   deny-by-default. `denyRead: ["~/"]` + explicit `allowRead` restores it. Linux SRT takes
   **literal paths only — no globs.**
3. **Keep the fail-closed preflight.** Same posture as ADR 0005: missing `srt`/`socat`/`bwrap`
   or a blocked userns dies with exact remediation. `--no-sandbox` stays the loud opt-out.
4. **Pin the version exactly.** `0.0.67` at time of writing; pre-1.0, config format may evolve.
   Treat an upgrade as a change that re-runs the conformance suite.

Keep from PR #90: the allowlist derivation (Anthropic API + the worktree's git remote), with
the URL-parsing bugs fixed — strip userinfo and any port from `https://` remotes, or a
credentialed remote leaks its token into process argv and never matches the allowlist anyway.

Deletes: `templates/egress-proxy.py`, `templates/nftables/hgt-egress.nft`, the `systemd-run`
scope wrapper, the egress pidfile lifecycle, the nftables preflight, most of the bind list.

## Non-goals
- #73 (minimal `CLAUDE_CONFIG_DIR`) and #75 (confine the `.git` bind) — both stand, now
  expressed as `allowWrite`/`denyWrite` entries rather than bwrap binds. Separate slices.
- #72 (`hgt init` installs the AppArmor profile) — unchanged; SRT uses bubblewrap too.
- TLS-terminating egress inspection. Domain fronting stays unsolved (ADR 0007 residuals).

## Acceptance criteria
- [ ] `hgt work <n>` launches claude through a pinned `srt` with a generated settings file; tmux
      and the human's shell pane are untouched on the host.
- [ ] Host env is scrubbed to `_SANDBOX_ENV_PASS`; a `GH_TOKEN` exported in the host shell is
      absent inside the jail (test asserts this).
- [ ] `denyRead: ["~/"]` + `allowRead` reproduces ADR 0005's read boundary: `~/.ssh` and
      `~/.config/gh` unreadable from inside.
- [ ] Egress allowlist covers the Anthropic API + the worktree's git remote and nothing else;
      credentialed/ported `https://` remotes parse to a bare host.
- [ ] Preflight fails closed with exact remediation when `srt`/`socat`/`bwrap`/userns is missing.
- [ ] `test/run.sh` is green **and terminates** — no real listener, no detached process. Shim
      `srt` as a PATH file under `test/shims/`, not a bash function (see #90: `setsid` execs
      past exported functions, which is how three tests silently passed while doing nothing).
- [ ] `templates/egress-proxy.py`, `templates/nftables/`, and the `systemd-run` wrapper are gone.
- [ ] README's sandbox + "Tests & CI" sections match reality.
